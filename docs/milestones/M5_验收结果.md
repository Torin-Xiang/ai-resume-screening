## 交付内容

1. `adapters/exporters/excel.py`：
   - 16 列：排名 / 简历文件 / 姓名 / 联系方式 / 初筛判定 / 得分 / 满分 / 命中加分项 /
     未通过硬门槛 / 待确认项 / 命中减分项 / **结论与原文证据** / 原文件路径 / 简历ID /
     **HR复核判定（下拉）** / HR备注；
   - 冻结首行、列宽适配、证据列自动换行、表头加粗；
   - "待确认"行浅黄底、"淘汰"行浅灰底（回应方案 §11 未决问题 4）；
   - 第二个 sheet「评分卡信息」记录 run_id / 岗位 / **评分卡版本** / 简历目录 / LLM 调用与 token，
     保证不同标准的结果可区分、可复盘（§4.4）。
2. `core/pipeline.py`：端到端编排（解析 → 提取（缓存）→ 评分 → 导出），适配器由上层注入。
3. `core/review.py` + `core/run_store.py`：HR 判定回写（通过/淘汰/待确认），回写结果落盘为
   `review.json`，是 v2 校准权重的唯一依据（§2.1 ⑤）。
4. CLI：`screen` / `review`。
